# `@lunx/native-linux-x64-gnu`

Optional Rust native binary for **lunx-dev** on Linux x64 (glibc).

Installed automatically via `optionalDependencies` when you `npm install lunx-dev`.
Keeps the main `lunx-dev` package lean (~≤1.6MB) while preserving Rust SWC + LightningCSS + rust-notify performance — the same packaging model as esbuild / `@swc/core`.

You normally do **not** install this package directly.
